

## 项目说明
~~~
这个项目（spbackend）是一个 React 19 + Vite 的前端项目，在cf的page下运行。
~~~

## 安装依赖
~~~
// 初始化项目，使用shadcn ui生成的样式
npx shadcn@latest init --preset b1Ymqvgiu --template vite --pointer


npm install react-router-dom

npx shadcn@latest add sidebar input drawer label dropdown-menu card badge 
npx shadcn@latest add avatar checkbox chart tabs select native-select
npx shadcn@latest add table collapsible breadcrumb dialog alert-dialog

npx shadcn@latest add toast

~~~
